# 教学模式图标

同一份几何（512 × 512、`translate(-38.4 -37.8) scale(1.15)`）的四个变体。基准版是 `icon-plate.svg`。

| 文件 | 用途 |
| --- | --- |
| `icon-plate.svg` | 带 22% 圆角纸色底板的方形图标：favicon、GitHub 头像、npm 页面、插件图标。 |
| `icon.svg` | 同一构图的透明底版，保留墨黑与朱红两色；嵌在纸色页面里用。 |
| `icon-line.svg` | 纯线稿、全 `currentColor`、无填充；设置页导航与侧栏标题用它。 |
| `icon-line-plate.svg` | 线稿加纸底板，仅用于预览线稿在深色环境下不走形。 |

## 规则

- **颜色**：墨黑 `#16120F`、朱红 `#9C3524`、纸色 `#FBF9F4`、板面米灰 `#E4DBCD`。朱红只出现在教鞭上，不做背景。
- **遮挡**：人压在黑板上时，用一个 `<mask>` 把人像（头 + 肩身）外扩后从黑板那一组挖掉，而不是移动构图。实心版外扩 26，线稿版 16。
- **比例**：头径 68 : 肩宽 110 = 0.618 = 1/φ；内容框 380 : 235 ≈ 1.617；V 领深度 82 : 肩身高度 132 ≈ 1/φ。
- **线稿线宽**：基准 22 / 18 / 14（512 视窗），在 16–24px 显示时按 `weight` 放大到 1.2–1.6px 的实际笔画。

`client.js` 里的 `TeachMark` 组件内嵌了 `icon-line.svg` 的同一份路径数据——客户端是手写的单文件模块，没有构建步骤，所以改动几何时两处都要同步。
