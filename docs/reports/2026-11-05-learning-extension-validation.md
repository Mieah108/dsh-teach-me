## 宿主兼容与接口纠正

完整运行验证基于 DSH `0.2.1-rc.5`。另从公开 npm 包读取 rc.3 的声明，确认 `conversation.input.dock`/InputZone、`agent/created`、`agent/status`、`agent/inbox/claimed`、`storageDomain`/DomainFacility.open 均存在，保持原最低版本声明 `>=0.2.1-rc.3`；没有宣称完成 rc.3 的完整浏览器集成测试。缺少后端时明确说明设置未保存，诊断入口仍保留；控件缺失时使用本地可访问折叠按钮，避免依赖宿主私有路径。

实施核实纠正了规划报告中的身份混淆：`preset-teach` 是 Loader 行 ID，预设配置 `config.id` 与实际会话投影均为 `teach`。数据域单元名使用宿主要求的下划线形式 `teach_session_preferences`。已通过真实接口验证，而非只按类型推测。

## 闭环发现并修复的问题

- 偏好保存回执曾把内部的“教学根 → 当前集合”字典当作界面集合列表；回执已统一为集合列表，真实保存后不再崩溃。
- 课堂“重新加载”曾遗漏原集合与内容版本；已固定参数并验证切换集合后仍在原课堂续读与提交。
- 深拷贝后的字典原型、历史提交所属版本、旧版题面评估及纯样式修订的进度延续均有针对性回归。
- 事实核查派遣计划使用只读快照文件路径，避免把整份 HTML 在每个派遣回执中重复传输。

## 明确边界

- 离线 HTML、参考页、PDF、外部网页与视频播放进度不做阅读同步；没有永久删除集合入口。
- 真实付费模型生成与联网核查未执行。测试验证派遣计划、预算闸门、实际启动来源匹配与报告校验，不把合成核查报告当作真实课程事实正确性的证明；最终完成状态由导师依据子代理实际返回的证据记录。
- 通用第三方 `sidebar_open` 只携带文件路径。当本次请求结束前当前集合已切换，自动打开会明确降级为从选课页选择原集合，避免同路径误开另一个集合；不擅自切换用户当前集合。
- 档案快照与索引不是回滚备份。降级必须恢复迁移前完整备份，不能让旧插件直接解释新增集合事件。
