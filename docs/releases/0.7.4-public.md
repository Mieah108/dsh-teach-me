`dsh-teach-me` 的首个公开发行版，为 DeepSeek Harness 提供教学预设、交互课程、练习评估和可持续积累的学习档案。

## 功能

- 根据学习目标和已有基础诊断起点，制定小课计划，结合讲解、练习与反馈推进学习。
- 提供可离线阅读的 HTML 课程，支持公式、闪卡、时间线、图表和本地媒体。
- 提供侧栏选课、正式作答提交、客观题判分、开放题模型初评和复习记录。
- 在学习工作区保存课程、题目、作答与评估，便于后续会话继续。
- 可选连接已有 Remotion 工程，同步动画源码并渲染静帧或视频；默认关闭。

## 安装与升级

```sh
dsh plugin --profile web add dsh-teach-me@0.7.4
```

安装后重启 DeepSeek Harness、刷新 Web 客户端，在新会话中选择「教学模式」。需要 pnpm 位于系统 PATH 中。

此前安装过本地包 `@local/dsh-teach-me` 时，先备份学习工作区与设置，移除旧包，再安装公开包。已有课程和学习档案应保留。

## 兼容性与验证范围

- 要求 DeepSeek Harness `>=0.2.1-rc.3`，设置页和侧栏课堂使用 Web 客户端。
- 源码校验使用 Node.js 26.4.0；其他 Node.js 版本需单独验证。
- 自动校验覆盖单元测试、插件自测、组件构建、技能与上游资源完整性、源码和运行包检查。
- 真实宿主课堂整链、模型批改质量、动画渲染权限与各平台体验需独立验收；本次发布不把自动测试等同于这些验收。
