# ADR-0008：插件文件操作使用工程围栏

日期：2026-10-25。状态：已接受；后续增加链接与原子写检查。


## 决定

插件在宿主进程中执行，因此自身文件操作必须使用独立围栏。工程根先 resolve/realpath；相对路径拒绝绝对路径、空/NUL、点段和盘符；最深已存在祖先及路径各段检查链接、硬链接、目录类型与根内归属。

写入仅限受管源码、注册标记块、受管元数据和产物路径；依赖目录、Git、环境文件、包清单与锁文件禁止写入。读取有大小限制，写入使用同目录临时文件和原子替换。同步在全部校验后发布。

## 边界

工程目录不因此对模型开放任意写权限，插件不替使用者装依赖或改包清单。路径检查仍不能等同目录句柄级无竞态保证，更不能覆盖渲染进程及其后代，见 ADR-0011。
