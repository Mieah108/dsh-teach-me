# ADR-0011：渲染进程权限需独立验收

日期：2026-10-26。状态：目标已接受；完整权限边界未验证。


## 决定

文件权限目标覆盖插件操作、渲染进程及其后代。声明的运行依赖、系统只读资源、字体、缓存、临时目录和联网需求必须有明确范围；不以插件文件围栏代替执行隔离证明。

当前实现使用 jobs 与 subprocess 管理生命周期，结算启动失败、超时、取消和完成。它不证明 Chromium 及后代进程已达到完整隔离。macOS 强边界 smoke、真实渲染链路和其他平台需要独立验收；不支持所需隔离的部署应停用自动代渲染。

## 取舍

信任工程与收紧文件 API 比完整执行隔离简单，但只提供前一层保证。诊断和发布说明需保留这种区别，不将代码存在、命令可运行或 unit tests 通过写成强隔离通过。
