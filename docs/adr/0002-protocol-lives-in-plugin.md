# ADR-0002：教学协议由插件注入并按能力条件化

日期：2026-10-25。状态：已修订；配置级条件化与可选阶段分层。


## 决定

persona 保留导师立场与能力入口，教学流程位于 `prompt/*.md`，由插件注入命名 section。阶段清单独立保存在 `prompt/stages/`。段序稳定，配置不变时保持固定前缀。

未配置动画时不注入动画段、不注册四个动画工具；配置后恢复完整动画协议。默认不按阶段裁剪。`prompt.stageLayering:true` 可显式启用阶段族分层，安全、提问、准确性、判分与授权规则固定保留；未知阶段、自定义目录或无法识别 Agent 时回退全量。

## 取舍与演进

最初采用全量协议；随后增加配置级动画条件化，再增加默认关闭的阶段族分层。分层只改变注入内容，不替代持久化阶段、权限或人工确认。

常驻字节、真实 token、缓存命中与费用分别记录；内容变少不能直接证明费用或教学效果改善。真实缓存与费用收益仍需实验。
