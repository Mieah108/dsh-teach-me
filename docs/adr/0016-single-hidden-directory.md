# ADR-0016：工作区状态集中于一个隐藏目录

日期：2026-10-27。状态：已接受；0.5.1 明确只读零写。


## 决定

教学工作区的档案、动画 staging 和教学根绑定状态集中到 `.dsh-teach-me/`，分别为 archive、animation-src 与 teaching-root.json。学习内容目录保持原位；复制教学根可携带相关状态。

旧 `.teach` 在允许修复的打开路径上整体 rename 到 archive。失败时继续使用旧位置，不在两处各写一半。只读查询不迁移、不初始化、不修索引。隐藏目录本身也检查链接，不能只校验 archive 子目录。

## 取舍

迁移只处理约定层级的旧目录，不扫描或猜测手工改名后的布局。受管动画工程中另有独立元数据目录，其归属由工程契约定义，不属于学习工作区的第二套档案。
