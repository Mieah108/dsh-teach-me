# ADR-0007：个人配置由 profile 设置行持有

日期：2026-10-25。状态：已修订；0.3.0 起使用精确包根的 host 行。


## 决定

工程路径和机器相关选项由 profile 的 `teach-settings` 行持有，入口为精确包根与 `entryRole:host`，不写入分发预设。设置页通过客户端 configForms 编辑 volatile 字段，host 暴露只读配置服务。

优先级为设置页值、预设行值、内置默认。未填字段不覆盖默认，工程空字符串表示关闭动画。修改后重启插件行或宿主。

## 取舍与演进

宿主描述配置数据不等于自动生成页面，因此客户端另行注册设置页。旧 `/settings` 子路径保留入口兼容，但不满足客户端发现；全局行还提供课堂服务，始终不注册教学工具。可编辑字段与界面范围见主 README。
