# ADR-0001：一个包提供预设、插件与客户端

日期：2026-10-25。状态：已接受；0.3.0 修订 host/runtime 入口。


## 决定

一个安装单元同时分发 `cordis.patch.yml`、插件、客户端和资产。预设内部的 `teach-me` 行使用 runtime 角色，教学工具、技能与提示词只属于教学会话；profile 全局 `teach-settings` 行使用 host 角色，负责设置和课堂服务。

资产用包自身位置解析，兼容目录链接安装。包名 `dsh-teach-me`，预设 ID `teach` 保持稳定。客户端发现使用精确包根，旧 `/settings` 入口只作为兼容别名。

## 取舍

避免两个独立包造成版本和安装错配，同时保持作用域隔离。全局 host 支持不等于全局注册教学能力。若以后需要跨预设复用，可拆出能力包；当前不增加这个部署层次。
