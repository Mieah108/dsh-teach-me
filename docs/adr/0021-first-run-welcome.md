# ADR-0021：首次安装的欢迎页只出现一次

日期：2026-11-07。状态：已接受，随下一个测试版发布。

装好插件之后，使用说明散在三个地方：预设选择器、对话里的「教学设置」按钮、`设置 → 教学模式`，还有一份默认关闭的 Remotion 动画。第一次装的人不会去读 README，于是把一个「只出现一次」的欢迎页放在宿主界面上，页面里写明它只出现这一次。

欢迎页是**客户端浮层**：注册在宿主 root 级 `shell.overlay` 槽，弹层外壳复用宿主 `Modal`（portal、焦点陷阱、Esc 关闭都是宿主的），正文是我们自己的 `TeachWelcomeBody`。宿主没有这个槽或没有 `Modal` 时静默不显示，不报错、不降级成页面顶上的横幅——那会挡住对话。

「已看过」存进 profile 设置行的 `welcome.seen`，而不是 localStorage。宿主设置服务（`dsh-settings`）只接受 volatile 路径，这个字段天然满足「写入即时生效、不重启插件行」；同时它跟着 profile 走，换浏览器、清缓存、换设备都不会让欢迎页复活。localStorage 只在一种情况下用：写入被拒或超时（只读 profile、接口失败）时记一个本浏览器的兜底标记，否则写不进去就意味着每次刷新都再来一遍，那正是这个功能最招人烦的失败方式。

判定口径是「字段还没被写成 true」，所以从旧版本升上来的人也会看到一次，之后不再出现。这是有意的：这一版才第一次有欢迎页，谁都没看过。真的想再看，走设置页的「重新显示欢迎页」——它把同一个字段写回 `false`，并清掉浏览器兜底标记；同一个 configForms 快照一更新，浮层当场重开，不需要刷新。

只读部署不弹。没有可写的地方记住「已看过」，弹出来就关不掉也记不住，反复出现比不出现更糟。恢复入口放在设置页而不是浮层里，是因为从浮层跳设置页需要跨页导航，宿主没有稳定接口；用一句文案指路加一个设置页按钮更可靠。

## 取舍

- **不把 localStorage 当主状态**：它只在单个浏览器里成立，换设备就会重新弹，不满足「只出现一次」。
- **不新开 host 接口或状态文件**：设置服务已经负责持久化、并发与回滚，再写一套只会多一处不一致。
- **不跟着版本号反复弹**：一次性是用户能看懂的承诺；想让人再看，必须是他自己按的按钮。
- **不让欢迎页承担教学任务**：它只讲「在哪里点什么」，课程、诊断与验收仍由教学模式自己走。
