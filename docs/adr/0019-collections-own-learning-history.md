# ADR-0019：教学集合拥有独立学习历史

日期：2026-11-04。状态：已接受，0.8.5-beta.1 实施。

教学集合既用于分类，也用于同一内容的多轮学习，因此不能仅作为课程标签。每个集合拥有独立的阅读、作答与评估历史；同一课在两个集合中学习时，历史互不覆盖。代价是课程与学习历史之间需要明确集合归属，而不能继续仅凭课程身份汇总全部学习状态。

2026-11-05 补充：跨集合复用课程时固定加入当时的内容版本，更新不自动传播，采用新版本需显式选择。采用新版后阅读进度从零记录，旧版阅读、作答与评估历史保留，不把旧版评估自动算作新版通过。正文、题目或依据变化构成内容新版，正文错字修正也包括在内；纯外观修改保留阅读状态。既有课程与学习历史归入默认集合，没有阅读数据时明确显示暂无记录。本记录不预先选择物理存储结构；迁移与旧版兼容通过实施前验证和备份回滚方案落实。

每个会话独立记住当前集合，切换只影响后续请求，已启动任务和已打开课堂保持原集合归属。复制集合只复制课程清单与固定版本，不复制学习历史；首版提供可恢复的归档，不提供永久删除。

归档只从默认活动列表隐藏集合，仍可查看、阅读并保存进度，已启动任务可以写回原集合；生成新的课程前需要恢复集合。
