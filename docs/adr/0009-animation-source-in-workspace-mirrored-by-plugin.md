# ADR-0009：动画源码属于工作区并单向同步

日期：2026-10-25。状态：已修订；0.3.0 起加入受管注册。


## 决定

每课源码先写到教学工作区 `.dsh-teach-me/animation-src/<slug>/`，由 `teach_animation_sync` 单向镜像到配置工程。源码可检查、复用并随课程维护；工程依赖不在每课重复安装。

inspect 只读；register 默认展示 diff，确认后维护标记块；sync 校验整批文件并原子发布，dry_run 不创建文件；render 通过后台 jobs 启动静帧或视频任务并返回 job ID。

## 取舍

工作区与工程分别保留源码，工程内手改不会反向同步。依赖由使用者安装。注册与归属策略由 ADR-0013/0014 定义；长任务不塞回一次工具程序的执行预算。
