# ADR-0017：复用组件并由学习者主动操作

日期：2026-10-27。状态：已接受。


## 决定

课程复用具有可核对来源的闪卡、时间线、图表及按需生成配方。组件在发行前构建成本地 JS/CSS，阅读课程无需运行上游平台；第三方原件、改编关系与许可单独记录。

HTML 是主要课堂，选择、揭晓、调参、单步与播放由学习者触发。答疑情境由学习者手动复制；持续自动观察和导师驱动整堂播放不作为默认能力。

## 取舍

成品组件与生成配方分别标识；提示词不能冒充已运行组件。按内容决定是否加载资源，不把所有组件无条件注入每课。复用减少重复实现的可能，但不提前承诺 token、生成速度或教学效果收益。

实际采用的 DeepTutor/OpenMAIC 文件及适配说明见根 ATTRIBUTIONS 与资产 UPSTREAM 清单。0.7.3 的原创动画接入指南保留受管制作链路，上游 Remotion 示例树不再分发。
