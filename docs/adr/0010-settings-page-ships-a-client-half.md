# ADR-0010：设置与课堂由客户端模块呈现

日期：2026-10-26。状态：已修订；0.3.0 起加入课堂页签。


## 决定

`client.js` 通过宿主模块加载与公开扩展点注册「设置 → 教学模式」、选课列表和课堂 tab。设置通过 configForms 读写 teach-settings 行，不读取宿主 UI 私有实现。

使用 `configForms.whileServed` 管理设置页生命周期；行不可用时不展示空表单。界面使用宿主主题变量，自带中英文文案。课堂通过宿主连接调用受控 RPC；配置页不是教学工具注册入口。

## 取舍

宿主配置服务只负责数据描述，不替第三方包生成整页 UI。客户端与 host 必须一起被发现，因此全局行使用精确包根。修改客户端后需要宿主重载；不含相关 UI 服务的部署不宣称具备这些界面能力。
