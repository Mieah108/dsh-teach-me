# ADR-0020：会话教学偏好跟随会话保存

日期：2026-11-05。状态：已接受，0.8.5-beta.1 实施。

事实核查等级与讲解深度的默认值用于新会话，对话内调整仅覆盖当前会话并在重新打开后保留。每次教学请求开始时固定本次偏好，后续调整只影响下一次请求，避免同一任务中途改变讲解结构或已启动的核查工作。

课程、集合与阅读记录随教学工作区搬迁，会话覆盖值跟随宿主会话；仅复制教学工作区不复制会话偏好。优先复用宿主持久化设施，不能为复用而写入只读会话头或依赖受限制的实验记录接口。保存设置失败时恢复最近成功值并反馈；阅读记录保存失败时允许继续阅读，但明确标识未保存。实际宿主数据域后端已通过保存、重开和隔离探针，兼容性记录见实施验证报告。

当前集合由会话独立选择；集合切换也不重定向已经启动的请求或已经打开的课堂。根据 2026-11-05 用户界面修订，对话内入口改为“教学设置”弹出按钮，默认关闭，与新会话“教学模式”预设选择器同排且风格一致；已有会话在标题操作区保留入口。不显示集合和档位摘要；点击后再显示具体选项。弹层和选项菜单复用宿主公开接口。此修订替代最初的内联折叠形式，偏好归属与生效时机不变。
