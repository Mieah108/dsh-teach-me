# ADR-0018：档案快照是可丢弃派生缓存

日期：2026-10-29。状态：已接受；不承诺性能指标。


## 决定

仅由显式维护命令或 Archive.createSnapshot 生成 snapshot.json。在原档案写锁中完整重放，再原子替换。快照包含格式、投影器指纹、工作区身份、前缀水位、状态、容忍事件与校验和，不新增事件、不截断或清理日志。

读路径仍验证完整 journal 哈希链，校验前缀锚点后才用快照继续重放尾部。快照或尾部投影失败时退回完整重放；重建索引强制全量。`useSnapshot:false` 可旁路，旧版本忽略新文件。

## 权衡与回滚

收益只能来自减少状态投影，读盘、JSON 解析与完整链验证仍为 O(n)，不承诺固定延迟或提速比例。checksum 检测损坏，不是签名，也不防有权重写整个档案的人伪造数据。

删除快照或关闭使用即可恢复全量重放，学习证据保持不变。若未来跳过日志前缀读取或压缩权威日志，必须另立决策。
