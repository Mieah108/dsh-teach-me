# ADR-0003：问题挂起与候答闸门

日期：2026-10-25。状态：已修订；0.3.0 起使用宿主官方提问。


## 决定

使用宿主 `ask_user_question` 的 timed 模式，使问题在一次工具程序结束后仍能保持可回答。pending 或等待窗口结束不表示批准；依赖答案的动作必须等待回答。

插件只维护候答闸门，读取宿主 userQuestions 投影，在仍有 active 问题时阻止依赖回答的写操作；读取、搜索和诊断可继续。默认开，可通过 `ask.gateWhileWaiting` 调整。

## 取舍与演进

早期同名自建提问工具已移除，避免重复维护 pending 状态和覆盖宿主协议。客户端问题卡使用宿主的呈现；本包不通过更改卡片文案或提高程序超时模拟回答确认。
