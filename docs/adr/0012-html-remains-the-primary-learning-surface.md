# ADR-0012：HTML 是主要课堂

日期：2026-10-26。状态：已接受；课堂交互已实现，真实整链需另验。


## 决定

正文、公式、例子和练习优先保留在课程 HTML；对话承担短引导、答疑与反馈。使用宿主侧栏承载课堂，同时保留独立浏览器离线阅读。

本地自测即时反馈，明确提交才保存正式作答；离线答案通过文件导出/导入，不默认后台自动同步。teach 的目标驱动、可信来源、最近发展区、小课、检索练习、间隔复习、速查资料和学习记录继续作为教学主线。

## 取舍

HTML 需要处理资源授权、题目挂点与回传，却能保持长文与公式可读性。普通宿主预览不是课堂回传接口；已有课程不自动升级为评估通过。
