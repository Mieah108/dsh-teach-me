# ADR-0004：技能分发与完整性校验

日期：2026-10-25。状态：已修订；0.7.3 固定 teach 来源并提供原创动画指南。


## 决定

教学模式随包注册两个技能：

- `teach` 保持上游原件，采用 MIT；固定到 `mattpocock/skills` 提交 `ad5400b930b297b0c0cb231ff1ffe42a7da666aa` 的 `skills/productivity/teach`。六个文件已按上游 Git blob/tree 核对。
- `teach-animation` 为本项目原创接入指南，描述 staging、受管注册、同步、静帧、渲染与资产边界，不冒称上游 Remotion 技能。

`skills/UPSTREAM.json` 记录每文件路径、字节数和 SHA-256。日常校验只读取仓库内容，拒绝缺失、额外或篡改文件，不依赖 HOME 中预装技能。更新上游来源需要重新核验固定提交、许可与文件清单；不能用本地目录一致代替上游来源证明。

## 调用与授权

teach 头部保留上游 `disable-model-invocation:true`，本包注册时允许模型在教学模式中调用；这是注册策略差异，原件不改。

0.7.3 不再分发原 Remotion 技能、示例代码和地图资产整树。动画工具继续使用使用者独立安装的工程与 Remotion 运行时。更完整 API 参考由官方文档提供；运行时的许可仍按使用者实体与用途适用。

## 取舍

默认技能不随上游自动变化，校验可在干净源码包中重现。内置上游参考资料比旧版减少；同时消除未闭环的第三方示例再分发范围，保留本项目动画接入契约。
