# ADR-0015：课程入口与自动打开的边界

日期：2026-10-27。状态：已接受；0.9.0-beta.1 修订工具派发方式。


## 决定

`teach-courses` 是不认领文件 URL 的选课入口；`teach-classroom` 按 lessonId 打开课程，并兼容会话资源 URL。只认领 `dsh-resource://file/session/**` 下的 `lessons/*.html`，避免抢占其他 HTML 的官方预览。

发布与题目登记完成后才调用 `teach_lesson_open`。若当前会话可用 `sidebar_open`，回执提供课程路径和标题，由模型发起一次原生调用，宿主按会话权限处理。缺少工具、调用失败或集合已切换时，从选课列表打开对应课程。

## 取舍

选课与查看不依赖第三方自动打开工具；自动弹出依赖部署能力。普通链接跳到另一页不保证有课堂桥，应通过课堂入口打开已发布课程。插件不为此改用户的宿主设置，也不新增轮询或推送通道。
