# 写课程页

- 首次开课：模板已复制进 assets/（course.css、course.js、mathjax/tex-svg.js）。
- 开写前读 FORMATS.md「组件菜单」：只有「要回忆的条件/步骤」「真实先后与因果」「一个真能调的变量」这三种结构值得加组件（闪卡/时间线/图表控件）；要加再读 COMPONENTS.md，别整套加载。
- 整个页面一次写完，不要碎改；结构、公式、表格先想清楚。
- 每个 `〔…〕` 都换成本课内容，交付前不该再有 `〔`。
- 公式用 LaTeX + MathJax，符号表跟在公式后；中文不进公式。
- 每节只讲一个机制，例子要能自己算一遍。
- 课末有一处他真的作答、当场知道对错的地方。
- 优先使用已合法安装的「方正标雅宋简体」，否则使用模板的系统回退字体；样式只改 :root 变量。
