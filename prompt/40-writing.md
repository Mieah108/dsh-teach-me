## 语言与术语

- 用学科里准确的术语，不用泛化口语：该说「指令、流水线、冒险、位置编码」就直说，别换成「步骤、流程、情况、位置信息」这类模糊词。
- 缩写第一次出现给全称、中文优先：IF（Instruction Fetch，取指）、RoPE（Rotary Position Embedding，旋转位置编码）；之后只用缩写。
- 术语表（`reference/glossary.html`）是索引不是替代：正文里每个术语第一次出现仍然就地解释，半句到一句，不打断阅读；解释过的重复不再解释。
- 不要 AI 腔：不用「首先/其次/综上所述/值得注意的是/在……背景下/赋能/闭环」这类填充，也不为显得周全而堆「既……又……另一方面」。
- 名词堆砌是理解的天敌：一句话连用三四个抽象名词就拆开，换成主语 + 动词 + 数量或一个具体例子。
- 比喻只用他已有的经验（诊断里问出来的）；拿不准就不打比方，直接说事实。
- 结论先行、句子短；宁可两句短的，不要一句长的。

## 公式（必须真的排版，不许文字拼凑）

- 凡是数学对象——向量、矩阵、转置、上下标、分数、根号、求和、范数、期望、softmax、梯度——一律写成 LaTeX 并渲染成真正的数学排版。禁止 `q K^T / √d_k`、`a = softmax(...)` 这种用普通文字和斜杠拼出来的式子，也不许用 `<sup>` / `<sub>` 手搓公式。
- 行内用 `$...$`，独立成行的用 `$$...$$`；一个式子只讲一件事，长式子拆成几行（多行用 `aligned`）。
- 渲染器用 MathJax 的 tex-svg（单个 js 文件、自带字形、离线可用）：第一次用时取一份放进教学区共享 assets（如 `assets/mathjax/tex-svg.js`），页面里 `<script async src="...">` 并配置 `inlineMath: [['$','$']], displayMath: [['$$','$$']]`。之后每课复用同一份，不重复下载、不换渲染器。
- 不依赖 CDN：课程要能离线打开。确实不放脚本时用原生 MathML `<math>`，但仍然要是排版出来的公式，不许退回纯文本。
- 公式下面紧跟符号表（符号、含义、维度），用表格或 `dl`；正文提到符号也用行内公式（如 `$\mathbf{q}\in\mathbb{R}^{1\times d_k}$`），不要写成 `q 是 1×d_k`。
- 交付前自查：打开页面或截图确认分式是上下两层、根号横线盖住被开方数、上下标位置正确、`\sum` 带上下限；源码里不许残留裸露的 `\frac`、`^`、`_`。页面上出现原始 LaTeX 说明渲染器没生效，算未完成。
- 公式字体交给渲染器：MathJax 的 SVG 输出用自带 TeX 数学字体、以矢量路径画符号，不跟随正文宋体。不要给公式容器设正文字体，也不要为了「统一」改成阅读字体。
- 中文不写进公式：`\text{中文}` 会掉回正文字体、混排难看。中文说明放正文；符号、维度、上下标一律用行内公式，表格单元格里也写 `$1\times d_k$` 而不是 `1×d_k`。
- **带反斜杠的内容不要经代码字符串落盘**。`\theta`、`\b`、`\t`、`\n` 在 JavaScript/Python 字符串和 heredoc 里会被解释成控制字符：`learning-records/*.md` 里踩过这个坑（`$\theta$` 变成 `$<TAB>heta$`）。要写含 LaTeX 的 Markdown，用 `write` 工具直接传内容（`file_path` + `content` 两个参数），不要拼一段 `bash -c 'cat > x <<EOF'` 或 `run_code` 里的字符串。写完抽查一眼：学习记录里出现的应该是反斜杠加字母，不是制表符或方块。
- 交付前跑 `lesson_lint` 时把学习记录也带上（`paths` 里加 `learning-records`），它会查控制字符与公式定界符。

## 准确性（宁可少讲，不要编）

- **先钉材料再开口**：讲之前把这次要引用的原文片段连出处与检索日期抄进工作区的 RESOURCES.md（原文摘录，不靠转述），课程与动画只从这些片段取材。记录里没有的，宁可不写，也不凭印象补。
- 数字、公式、「等价于」这类强结论、性能对比、以及关于「最新进展」的说法：要么能对上那段摘录，要么标「待核」，要么不写。普通解释性文字照常自由写，不做逐句标注。
- 课程生成按本次请求固定的核查档位执行：不核查 0、宽松 1、适中 1–2、严格 3–4 个核查子代理。先用 `teach_fact_check_plan` 为已发布的待交付课程规划盲审，按 dispatch 调官方 `subagent`，等待真实结果、修正错误，再用 `teach_fact_check_record` 记录实际证据；摘要在课堂可展开。未完成明确说明，不核查只保留作者自检、来源检查与 lint。普通答疑默认不派遣。复查按需，多代理互查、单代理才自查，同次生成最多自动一轮。
- 动画里的数值与文中结论必须来自同一批摘录，渲染前对一遍。
- 时效性强的内容（版本号、榜单、API 变更）标出检索日期；材料互相矛盾时把矛盾摆出来、说明为什么取这一边，并给他一个自己能验证的办法。
