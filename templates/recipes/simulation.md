# 局部实验配方

由 OpenMAIC `simulation-content/system.md` 适配（MIT），复用变量/预设契约、运行状态、重置及响应式检查项。来源见 [UPSTREAM.json](UPSTREAM.json)。已有组件可用时只填数据；本配方用于必要的小型定制，不建立通用模拟平台。

## 输入与状态

先写本实验要验证的一句话，再列变量的名称、单位、范围、默认值和两个有区别的情境。计算和显示来自同一个函数；区分“刚修改的输入”与“已经执行并显示的结果”，过期结果要明确标记或重算。

```json
{
  "variables": [{"name":"capacity","label":"容量","min":1,"max":16,"default":4,"unit":"项"}],
  "presets": [{"name":"小容量","variables":{"capacity":2}}],
  "state": {"running":false,"ended":false,"step":0}
}
```

这份 JSON 是规划示例，不要求新增模型工具或将所有课程编译为这种结构。控件写在课程局部容器内，复用现有图表/表格/样式。按钮、参数、结果要能用一句话说明其作用；输入没有依据时先补足材料与口径。

## 保留上游的重置原则

```js
// 适配自 OpenMAIC：恢复全部实验状态，再从同一状态重画。
function resetSimulation() {
  state = { ...initialState };
  syncControls(state);
  updateResult(compute(state));
}
```

`initialState` 必须与控件默认值一致；嵌套状态需独立复制。启停依据状态变量，不能通过按钮文字判断；结束后的“重新开始”先重置再运行。含时间推进时用 requestAnimationFrame 并在暂停/卸载时停止；单步足以说明机制时优先单步，不为了动而连续播放。

## 输出约束

- 保持一课一个小成果。先让学习者预测，再调参或执行，最后说明为何不同；不要只提供滑块和数值。
- 用当前暖纸/深色主题、系统字体和本地 MathJax。控制面板在窄屏堆叠，和 Canvas/SVG 分开，不覆盖读数；单位始终可见。
- 支持键盘和原生表单标签；按钮至少有清楚的 focus 与禁用状态。Canvas 配同源文本读数或结果表，不能只靠颜色表达。
- 本地操作不请求模型；独立 HTML 不依赖 DSH、外部字体、CDN 或动态模块下载。需要脚本和素材时列入发布清单。
- 需要答疑时在 `data-teach-context` 容器内用可见的 `p[data-teach-state]` 写明输入、步数及已呈现结果，由学习者手动复制；不发送未揭晓解答、不持续采集历史。
- 需要验收时另用现有 `.quiz` 或解释题挂点，按既有协议显式提交；看完演示、调到正确参数和“运行结束”不自动等于掌握。

## 检查完成才交付

正常输入、边界输入、暂停继续、预设切换、全部重置、过期结果、重复操作、窄屏和离线逐项走一遍。只修失败部分；不要把含 div/html 标签视为功能已经验证。
