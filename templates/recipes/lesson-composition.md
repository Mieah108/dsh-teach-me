# 内容组合配方

由 DeepTutor `page_planner.yaml` 适配，来源与许可见 [UPSTREAM.json](UPSTREAM.json)。保留“按目标选择表达”和“自然衔接”，移除上游固定块数、长章节字数与 Manim 要求。

## 输入

只需本课的一个主机制、学习者起点、可检验目标、高可信材料与已知误区。已有诊断和档案可直接使用，不重问。

## 选表达

| 要让学习者做到什么 | 优先表达 |
| --- | --- |
| 区分相近概念、判断边界 | 对比表、反例、自测 |
| 记住术语或条件 | 少量闪卡，先回忆后翻面 |
| 解释因果或状态关系 | 静态示意图；确需探索时再加节点揭示 |
| 看清历史顺序 | 时间线；算法执行过程用单步实验，不套历史时间线 |
| 复算推导 | 正文公式、具体数值例、换参数验收 |
| 探索变量关系 | 现成图表＋局部控件；缺少合适组件时读实验配方 |
| 观察文字难讲清的变化 | 先提动画案；获准后复用 Remotion 工程 |

先用 [FORMATS](../FORMATS.md) 和 [COMPONENTS](../COMPONENTS.md) 的现成结构。组件能表达时只填数据；自测继续使用现有 `.quiz`，不引入另一套判分。正文仍是主课堂，不为组件多样性把主题拆碎，也不强制每课有动画或实验。

## 最小计划与产出

用一张小表确定“目标 → 表达 → 学习者动作 → 怎样知道做对”，然后直接写课；不另建章节编译器或复杂中间 DSL。每个图、练习或实验前说明为何需要它，结束后用一句话回到主机制。正文、组件、字幕使用同一术语和同一批材料数据。

交付前核对：目标都能验收、例子可复算、组件有用才出现、换情境题不只是重复原例。课件写完或练习被揭晓不等于学习者已经评估通过。
